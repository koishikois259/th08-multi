一、远程联机（以樱花穿透为例）
主机端：
樱花穿透中选择一个靠近双方的节点并创建udp隧道，本地ip填127.0.0.1，绑定本地端口17708
而后打开multi-launcher.exe，选择host，host ipv4填127.0.0.1，host port与local port均填写17708，
input delay可根据网络延迟调整，默认为3两端需一致，往大填游戏延迟会变大但更适用于网络差的环境，
若节点网络条件较好可以往小填。

客机端：
主机端创建节点后将节点ip发给客机端，形如12.34.56.78:11111（下面教程以该ip为例）
打开启动器，选择guest，host ipv4填主机发的节点ip（本例中为12.34.56.78），host port填主机节点port（本例中为11111），
local port填0，input delay与主机一致即可，而后点击connect，等待主机开始。

游玩前最好确保双方均是全屏或均是窗口，可在custom.exe里设置。

主机点击start both game后，主客机最好等待双方均进入游戏主页面后，再由主机进行关卡选择，否则可能有不同步bug。（v0.32需注意,v0.33该问题已修复）

若全屏游玩，则游玩过程中最好不要切屏，否则可能会导致连接丢失。

存档统一使用主机的存档记录，即解锁进度与主机相同。
联机开始时双方初始残机数以主机（P1）的游戏设置为准，客机（P2）的本地初始残机设置会被忽略；主机未修改时默认均为 2。

二、v0.4 本地双设备游玩（一台电脑、一个游戏窗口）

1. 准备两台不同的输入设备：两把实体键盘、键盘加手柄，或两个手柄均可。
   笔记本自带键盘加一把外接键盘也算两台设备；不能让 P1、P2 共用同一台设备。
2. 先将设备连接到电脑，运行 th08-multi-launcher.exe，在主页面点击
   Local play (multi input)。本地模式不需要选择 Host/Guest，也不需要连接网络。
3. 在第一台设备上按一次“确认键”，等它出现在设备列表后，再按第二台设备的
   “确认键”。请一台一台按，不要两人同时按。键盘的确认键是 Z；手柄可按确认/
   射击键。启动器在识别手柄时也接受其他手柄按钮，以兼容自定义按键。
   列表最初为空是正常的：它不会把 Windows 报告的虚拟键盘和手柄接口直接列出来。
4. 在 Player 1 和 Player 2 下拉框分别选择对应的设备，确认两项不是同一台设备，
   然后点击右下角 Start local game。游戏只会打开一个窗口。
5. 由 P1 的设备操作主菜单和难度选择。进入队伍选择后，先由 P1 选择并确认队伍，
   再由 P2 使用自己的设备选择并确认；随后两人分别用各自设备游玩。

本地游玩使用这台电脑的 score.dat 存档和初始残机设置，资源共享/独立规则与
双人联机相同。可以在 custom.exe 中设置窗口模式，建议首次测试先窗口运行。
如果插拔了设备、列表识别错误或换了输入设备，请回到启动器点击
Refresh devices，再按上述顺序重新按确认键并选择 P1/P2。
手柄双接口识别和各种硬件组合仍需实体设备测试；若一台手柄出现两次，请记录
设备名称、按键顺序和 Windows 控制器列表，反馈给项目维护者。
